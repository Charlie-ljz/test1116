# 金禾點餐 × Google 試算表（Apps Script）安裝說明

## 運作方式

```
網站 (GitHub Pages)
  ├─ 開啟時 ── GET  ?action=menu ──▶ Apps Script ──▶ 讀「商品」工作表（菜單、價格、售完）
  └─ 結帳時 ── POST 訂單 JSON ─────▶ Apps Script ──▶ 重新驗價 → 寫入「訂單」「明細」→ Email 通知
```

- **菜單由 Sheet 管理**：改「商品」工作表的價格、上架、售完，約 1 分鐘內網站就會更新。
- **伺服器端重新驗價**：網站送來的金額只是核對用，實際金額一律以 Sheet 的價格計算，顧客無法在瀏覽器改價。
- **不收款**：內用／外帶為到店付款，宅配為貨到付款（訂單的「付款狀態」可手動改成已付款）。

## 一、建立 Sheet 與 Apps Script（約 10 分鐘）

1. 到 [Google 試算表](https://sheets.google.com) 建立一份新試算表，命名例如「金禾訂單」。
2. 選單 **擴充功能 → Apps Script**。
3. 把 `Code.gs` 的全部內容貼到編輯器（取代預設的 `myFunction`）。
4. 左側 **專案設定（齒輪）→ 勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」**，回到編輯器開啟 `appsscript.json`，貼上本資料夾的 `appsscript.json` 內容。
5. 上方函式選單選 **`setup`**，按 **執行**。第一次會要求授權（可能出現「Google 尚未驗證這個應用程式」→ 進階 → 前往…，這是你自己的腳本，可放心）。
   - 會自動建立 4 個工作表：`商品`、`訂單`、`明細`、`設定`，並填入預設菜單。
6. 到 **`設定`** 工作表，把 **店家通知信箱** 填入你的 Email（新訂單會寄到這裡）。

## 二、部署成網頁應用程式

1. Apps Script 右上 **部署 → 新增部署作業 → 類型選「網頁應用程式」**。
2. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
3. 按 **部署**，複製「**網頁應用程式網址**」（格式 `https://script.google.com/macros/s/…/exec`）。
4. 在瀏覽器直接開 `網址?action=ping`，看到 `{"ok":true,...}` 代表成功。
5. 把網址貼到網站 `index.html` 的 `const GAS_URL = "";` 引號中（或把網址交給 Claude 代為設定），再推送上線。

> 之後每次修改 `Code.gs`，都要 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署**，網址不會變。
> 只改 Sheet 內容（菜單、設定）不需要重新部署。

## 三、測試

1. 在 Apps Script 執行 **`testOrder`**，`訂單`／`明細` 應各出現一筆，店家信箱會收到通知信。
2. 到網站實際點餐一筆，確認：Sheet 有資料、店家與顧客（填 Email 時）都收到信。
3. 測完把測試列從 `訂單`／`明細` 刪除即可。

## 四、日常操作

| 想做的事 | 怎麼做 |
|---|---|
| 調整價格、品名、圖片 | 改 `商品` 工作表對應欄位 |
| 暫時賣完 | 勾選 `商品` 的「售完」（網站會顯示「售完」並無法加入購物車） |
| 下架商品 | 取消勾選「上架」 |
| 新增商品 | `商品` 新增一列（id 不可重複；分類為 `potsticker`／`dumpling`／`soup`／`side`／`gift`） |
| 暫停接單 | `設定` 的「營業中」改為 `FALSE` |
| 改運費、門市、通知信箱 | 改 `設定` 工作表 |
| 處理訂單 | `訂單` 的「狀態」下拉：待處理 → 製作中 → 已完成 → 已取餐／已取消 |

### 工作表欄位

**商品**：`id`、分類、名稱、說明、價格、單位、標籤、圖片網址、上架、售完、排序
**訂單**：訂單編號、建立時間、狀態、取餐方式、門市、姓名、電話、Email、宅配地址、備註、商品小計、配送費、應付總額、付款方式、付款狀態、明細摘要、通知結果、requestId
**明細**：訂單編號、商品ID、商品名稱、單價、數量、小計（每個品項一列，方便統計）
**設定**：店名、店家通知信箱、營業中、配送費、門市清單、訂單編號前綴

## 五、安全與限制

- 網址是公開的（網站要能呼叫），所以伺服器端有：重新驗價與取餐規則檢查、欄位格式驗證、同一電話 10 分鐘最多 5 筆、防機器人隱藏欄位、重複送出保護（requestId）、避免試算表公式注入。
- 一般 Gmail 帳號每天可寄約 100 封信（Google Workspace 約 1500 封）。信寄失敗不影響訂單，會記在「通知結果」欄。
- 訂單編號格式：`JH` + 年月日 + 當日流水號，例如 `JH261116-001`。
- 個資（姓名、電話、地址）只存在你的 Google 試算表，請勿隨意共用該試算表給不必要的人。
