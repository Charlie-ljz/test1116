# 金禾點餐 × Google 試算表（Apps Script）安裝指南 v2

## 運作方式

```
網站 (GitHub Pages)
  ├─ 開啟時 ── GET  ?action=menu ──▶ Apps Script ──▶ 讀「商品」（菜單、價格、售完）
  └─ 結帳時 ── POST 訂單 JSON ─────▶ Apps Script ──▶ 重新驗價 → 寫入「訂單」「明細」→ Email 通知
```

- 菜單由 Sheet 管理，改價格／售完／下架約 1 分鐘內生效。
- 伺服器端重新驗價與檢查取餐規則，顧客無法在瀏覽器改價。
- 不線上收款：內用、外帶到店付款；宅配貨到付款。

## 部署只有一個地方最容易錯

部署網頁應用程式時，這兩個設定**必須**是：

| 欄位 | 必須選 |
|---|---|
| 執行身分 | **我**（你的帳號） |
| 誰可以存取 | **所有人** |

> 若「執行身分」選成「存取網頁應用程式的使用者」，「誰可以存取」就不會出現「所有人」，網站會被擋住。先改執行身分，再選存取權限。

## 步驟

### 1. 建立試算表與貼上程式
1. 到 [sheets.google.com](https://sheets.google.com) 建立空白試算表（名稱：金禾訂單）。
2. **擴充功能 → Apps Script**。
3. 刪掉預設程式，貼上 `gas/Code.gs` 的全部內容，按 💾 儲存。
4. （建議）左側 ⚙️「專案設定」→ 勾選「在編輯器中顯示 appsscript.json」→ 回編輯器打開 `appsscript.json`，貼上 `gas/appsscript.json` 內容並儲存。這會預先把部署預設設為「我」＋「所有人」。

### 2. 初始化
1. 回到試算表分頁，**重新整理頁面**，上方選單列會多出 **「金禾點餐」**。
2. 點 **金禾點餐 → ① 初始化**，首次會要求授權：選你的帳號 →（若出現「Google 尚未驗證」）進階 → 前往「金禾點餐（不安全）」→ 允許。
3. 初始化完成會建立 `商品`、`訂單`、`明細`、`設定` 四個工作表與預設菜單。
4. 到 `設定` 工作表，把「店家通知信箱」填入你的 Email。
5. 點 **金禾點餐 → ② 檢查設定**，確認顯示 ✅。
6. （選用）**③ 寄測試信**、**④ 寫入一筆測試訂單**，確認收到信、`訂單`／`明細` 有資料（測完刪除該列）。

### 3. 部署
1. Apps Script 右上 **部署 → 新增部署作業**，左側 ⚙️ 選 **網頁應用程式**。
2. 說明可留空；**執行身分：我**；**誰可以存取：所有人**。
3. 按 **部署**（需要授權時再允許一次），複製「網頁應用程式網址」（結尾必須是 `/exec`）。

### 4. 驗證
開**無痕視窗**貼上 `網址?action=ping`，應看到：

```json
{"ok":true,"version":"v2","time":"..."}
```

再試 `網址?action=health`，`ok` 應為 `true`（否則 `problems` 會告訴你缺什麼）。

### 5. 接到網站
把網址貼到專案的 `config.js`：

```js
window.JINHE_CONFIG = { GAS_URL: "https://script.google.com/macros/s/.../exec" };
```

（或把網址交給 Claude 代為設定。）推送上線後，在網站按 `F12` → 主控台輸入 `jinheCheck()` 可再次檢查後端。

## 日常操作

| 想做的事 | 怎麼做 |
|---|---|
| 改價格、品名、圖片 | 改 `商品` 對應欄位 |
| 暫時賣完 | 勾選 `商品` 的「售完」 |
| 下架 | 取消勾選「上架」 |
| 新增商品 | `商品` 新增一列（id 不重複；分類：`potsticker`／`dumpling`／`soup`／`side`／`gift`） |
| 暫停接單 | `設定` 的「營業中」改為 `FALSE` |
| 改運費、門市、通知信箱 | 改 `設定` |
| 處理訂單 | `訂單` 的「狀態」下拉選單 |

> 只改 Sheet 內容不需要重新部署。修改 `Code.gs` 後要：**部署 → 管理部署作業 → ✏️ → 版本選「新版本」→ 部署**，網址不變。

## 疑難排解

| 症狀 | 原因與處理 |
|---|---|
| 無痕視窗開 `?action=ping` 要求登入 | 「誰可以存取」不是「所有人」，重新部署並改正 |
| 看不到「所有人」選項 | 先把「執行身分」改成「我」 |
| 網址結尾是 `/dev` | 那是測試網址，請用「部署」產生的 `/exec` |
| `ping` 正常但網站菜單沒更新 | 強制重新整理（Ctrl+Shift+R）；確認 `config.js` 已填網址並已上線 |
| 訂單有寫入但沒收到信 | 查 `訂單`「通知結果」欄；檢查「設定」信箱、垃圾郵件匣；一般 Gmail 每天約 100 封上限 |
| 網站主控台輸入 `jinheCheck()` 回傳非 JSON | 同第一列，權限或網址問題 |

## 安全與限制

- 網址是公開的，所以伺服器端有：重新驗價、取餐規則、欄位驗證、同一電話 10 分鐘最多 5 筆、防機器人隱藏欄位、重複送出保護、避免試算表公式注入。
- 訂單編號格式：`JH` + 年月日 + 流水號，例如 `JH261116-001`。
- 個資只存在你的試算表，請勿隨意共用。
